# Transformer 架构与自注意力机制

## 要解决的问题

在 Transformer 之前，序列建模主要依赖循环神经网络（RNN / LSTM）。循环结构有两个固有代价：一是**无法并行**，第 t 步的计算依赖第 t-1 步的隐状态，训练时无法沿时间维度展开并行计算；二是**长程依赖衰减**，信息要经过逐步传递才能跨越较长距离，梯度容易在传播中消失或爆炸。

Transformer（Vaswani 等，2017）用注意力机制替换了循环结构，使序列中任意两个位置之间的交互路径长度恒为 1，同时让整段序列的计算可以并行。

## 自注意力机制

自注意力的核心是把每个位置的输入映射为三个向量：查询（query）、键（key）、值（value）。对位置 i，注意力输出是值向量的加权和，权重由 query_i 与所有 key_j 的相似度经 Softmax 归一化得到：

```
Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
```

其中 √d_k 是缩放因子。若不缩放，当维度较大时点积的方差会随维度增长，Softmax 会进入梯度极小的饱和区。

**为什么需要缩放**：假设 query 与 key 的各分量独立且均值为 0、方差为 1，则点积的方差约为 d_k。除以 √d_k 使方差回到 1 量级，Softmax 的分布不至于过度尖锐。

## 多头注意力

单次注意力只能表达一种关联模式。多头注意力把 Q、K、V 投影到 h 组低维子空间，各自独立计算注意力后拼接再投影。不同头可以分别关注语法依赖、位置邻近、语义共指等不同关系，相当于让模型在多个表示子空间里并行寻找关联。

## 位置编码

自注意力本身对输入顺序不敏感——打乱顺序得到的是同一组加权和。因此需要显式注入位置信息。原始论文使用正弦位置编码，后续工作多改用可学习的位置嵌入，近年则普遍采用旋转位置编码（RoPE）等相对位置方案，以便更好地外推到训练长度之外。

## 复杂度与主要局限

- **时间与显存均为 O(n²)**，n 为序列长度。序列翻倍，注意力矩阵规模变为四倍，这是长上下文的主要瓶颈。
- **数据需求大**：缺少循环结构带来的归纳偏置，通常需要比 RNN 更多的训练数据才能达到同等效果。
- **位置外推能力有限**：超出训练长度后性能下降，需要通过位置编码设计或插值方法缓解。

针对二次复杂度，出现了稀疏注意力、线性注意力、滑动窗口注意力等变体，在长序列场景下以一定的表达能力换取效率。

## 影响范围

Transformer 最初用于机器翻译，此后成为自然语言处理、语音、计算机视觉（ViT）、蛋白质结构预测（AlphaFold 系列）等方向的通用骨干结构。当前主流大语言模型几乎都建立在这一架构之上，区别主要在于规模、位置编码方案、归一化位置与注意力变体。
